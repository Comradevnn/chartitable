# Cinderwell Community Pantry (host site, charity id demo-pantry-a)
- Structure: index.html (header, quote hero, tile row, who we serve, history/what we do, feature, news x5, slot, newsletter + donate band, footer), donate.html, about.html, get-food.html. Static, no build. `styles.css` has class selectors only, so injected slot content is never restyled; no rules on `.ct-*`.
- Contract: three empty `data-impact-slot` sections on every page, each inside `.wrap` (1180px column); `[data-impact-slot]:empty{display:none}`; every Donate link is `a[data-impact-donate][href="donate.html"]`; layer script tag with `data-charity="demo-pantry-a"`; `--ct-*` vars on :root.
- Palette: deep teal #0f5b57 / #0a3533, marigold #f2b632, cream #fbf6ea, ink #1c2b2a, muted #4a5a58. Type: Besley (display) + Atkinson Hyperlegible (text), self-hosted in `fonts/` (OFL files included).
- Art: all SVG in `img/` (hero, tile, poster, five news thumbs, map, favicon) generated procedurally; wordmark logo is inline SVG in each header/footer. Nothing is a photo or a real logo.
- Preview: `?preview=1` (filled) or `?preview=empty` runs `preview.js` with `donor-view.*.json`; `site.js` also loads `preview-slots.css` (copy of `docs/design/ct-slots.css`) in preview mode only, because the real layer bundles those styles. Copy is refreshed by hand if the CSS changes.
- Verified in browser (tab closed after): 1280/768/390 on all four pages, no horizontal overflow (scrollWidth equals viewport); index and donate in plain and ?preview=1 states at desktop and 390; hamburger toggles aria-expanded and opens a full-width list; internal links and #anchors checked by script; header Donate, nav, buttons are at least 44px tall.
- Layer button note: `.ct-next-link` renders about 42px tall from the layer's own padding (host does not override it). White text on #0f5b57 passes AA.
- Honest figures: every stat names its year and basis (2025, weighed counts, sign-in sheets). Names, address, phone (555 range) and `.example` email are fictional. Footer social links point at example.com.

## Contract v2 usage (index.html only; about/donate/get-food keep their v1 slots; T29, D19)
- Regions (default markup stays for strangers; `<template data-impact-for="NAME">` at the end of `<main>` is cloned for a recognized donor): `greeting` (empty strip above the header, requires firstName), `hero` (wraps the founder-quote hero, id `impact`), `stat` (the middle stat tile itself, requires since), `next` (empty callout above the volunteer section, requires next), `band` (the `.band-donate` half, requires next). No `data-impact-slot` is needed: the hidden on-switch div and the donate-href MutationObserver are gone (the layer rewrites `a[data-impact-donate]` inside clones).
- Hero variants, tried in order by `data-impact-when`: `just-gave` (`state:just_gave`: headline, "Your gift" record line, body, a host-written "What happens next" line with no numbers, one next-step button; no tiles, no estimates), `news` (`state:news`: headline, gift line, buttons, then "New since your last visit" tiles from `sinceRecords` (falls back to `records`), then the dashed "Your share, an estimate" box), `thanks` (default for first_impact, repeat, returning, lapsed: headline, gift line, body, buttons, tiles from `records`, estimate box). The headline uses `data-ct-text="headline"` with a host fallback when absent (`data-ct-if="!headline"`), the paragraph uses `body` with a `story` fallback.
- Next step: every button is `data-ct-href="next"` with host hrefs `data-ct-href-volunteer="#volunteer"` and `data-ct-href-share="#news"` (give kinds take the API donate href). Its label is `<span data-ct-text="nextLabel">`; if the label is missing the span is removed and `.next-btn:empty::before` supplies "Your next step". (`nextLabel` is not a valid `data-ct-if` key, so the fallback is CSS, not markup.) Where the next step already is "give again" (repeat, lapsed) the separate "Give again" donate button is hidden with `data-ct-if="!state:repeat+!state:lapsed"`.
- `stat` region: requires `since`; date via `data-ct-if="sinceDate"`; one since record (limit 1) in a `data-ct-live` container, one since estimate in a dashed box labelled "Your share, an estimate".
- Records vs estimates: every estimate renders only through `data-ct-text="estimate"` inside a visibly labelled dashed, italic, unfilled box; records use the site's solid `.tile.tile-stat` component; the donor's own gift ("You gave $X on DATE", `lastGift`/`lastGiftDate` inside `data-ct-if="gifts"`) is a solid-ruled record line. No number about the donor is written in host copy.
- Motion hints (all inert without the layer's motion): `data-ct-animate="count"` on record numbers only (never on estimates), `draw` on estimate boxes, `reveal` on the template roots of the below-the-fold `next` and `band` regions, `data-ct-live` on the hero tile list and the stat region's record container. `<span class="ct-new-tag">Just logged</span>` sits inside each record; `.ct-new-tag{display:none}` and `[data-ct-new] .ct-new-tag{display:inline-block}` in styles.css. The old host `region-in` fade is removed (the layer owns the swap animation); the page is complete with no motion.
- View transition names (unique per document): `ct-headline` on both `#hero-quote` and `#donor-hero-h` (they never coexist), and `ct-hero`, `ct-tiles`, `ct-next`, `ct-volunteer`, `ct-band`, `ct-news`, `ct-serve`, `ct-story` on the matching `main > *` sections so the re-order glides.
- Re-composition: under `html[data-impact-active]` `<main>` becomes a flex column with `order`: hero, tiles, next, volunteer (id `volunteer`), band, news, who we serve, our story. Strangers keep DOM order. `.hero-region` keeps the hero's min-height so the swap does not collapse.
- `donor-view.sample.json` carries the v2 fields (headline, body, nextStep.label, donor, rev, `live: null`) so the dev preview never polls. `?preview=1` (preview.js) still only fills v1 slots, so on index.html it shows the banner and nothing else; use `node layer/test/variant-server.mjs` (`/cinderwell/?ct=fx.a.<state>`) to see every state.
- Header/footer logo links got `min-height:44px` (they were 37px tall).
