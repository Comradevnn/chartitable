# Brindlecote Food Bank (demo host, charity id demo-pantry-b)
- Structure: utility bar, header (6 nav items, Donate + Give Monthly), hero, three-card row, FY2025 stat band, since-last-visit slot, dollar bar, events, news, partner marks, next-step slot, newsletter, 4-column footer. Pages: index, donate, get-help, about.
- Slots: index.html is on contract v2 (see below). about/donate/get-help keep three empty v1 `data-impact-slot` sections inside `.wrap` containers (hero under header, since-last-visit under stat band, next-step above newsletter); `[data-impact-slot]:empty{display:none}`. Every link to donate.html except Give Monthly (`donate.html?monthly`) carries `data-impact-donate`.
- Layer: `layer.js` script tag with `data-charity="demo-pantry-b"`; `--ct-*` vars on :root. No rules on `.ct-*`, no bare element color rules, no `section`/`h2`/`p` element selectors (layer :where() rules win).
- Palette: white, ink blue #12263f, slate #4a5b70, soft #f3f6f9, one warm accent #b34a08 (#f2a65a on dark). Font: Commissioner 400/500/700 self-hosted in fonts/.
- Art: generated SVG scenes in img/ (warehouse hero, card, news, banner scenes, logo mark, partner marks). No photos, no real logos. Content is fictional (Tarnwick County, 555 phone, .example emails).
- Preview: `preview.js` + `donor-view.*.json` (copied from _preview; sample nextStep href changed to index.html#volunteer so it works on every page). Use `?preview=1` or `?preview=empty`.
- Serve: `python3 -m http.server 5522 --directory demo-sites/hosts/brindlecote`.
- Verified at 1280/768/390, plain and ?preview=1, all 4 pages: no horizontal overflow, no duplicate ids, internal links and anchors resolve, text contrast AA (Donate white on #b34a08 = 5.4:1), mobile menu (aria-expanded, Escape), tap targets >=44px except the layer's own `.ct-next-link` (42px tall, from ct-slots.css).

## Contract v2 usage (index.html only; T29, D19)
- Regions (default markup stays for strangers; templates sit at the end of `<main>`): `hero` (`div.hero-region` wrapping the default hero, requires `headline|story`), `since` (empty `div.since-region` where the old since slot was, right under the stats band, requires `since`), `next` (empty `div.next-region` above the newsletter, requires `next`). The three v1 slot sections are gone from index.html. No `data-impact-slot` needed.
- Hero variants (`data-impact-when` in order): `just-gave` (`state:just_gave`: headline, "Your gift" record line from `lastGift`/`lastGiftDate`, body, host "What happens next" line with no numbers, one next-step button; no records, no estimates), `repeat` (`state:repeat`: headline, "A record of your gifts" list via `data-ct-each="gifts"` (amount, date), body, next-step button, the last logs, dashed estimate box), `news` (`state:news`: lighter hero with headline, gift line, "See what was logged" anchor to the since region plus the next-step button), `thanks` (default: headline, gift line, body, next-step plus "Give again" donate button hidden for repeat/lapsed, last logs, estimate box). Headline falls back to host text when absent; `body` falls back to `story`.
- `since` template (`#since-visit`): `sinceDate` via `data-ct-if`, up to 3 `sinceRecords` (count, unit, date, note, photo), then a dashed "Your share, an estimate" box from `sinceEstimates`. `next` template: callout with `nextText` and the next-step button.
- Next-step buttons: `data-ct-href="next"` plus host hrefs `data-ct-href-volunteer="#volunteer"` and `data-ct-href-share="#news"` (give kinds take the API href). Label via `<span data-ct-text="nextLabel">`; if the label is missing `.next-btn:empty::before` supplies "Your next step" (`nextLabel` is not a `data-ct-if` key).
- Records vs estimates: records are solid, top-ruled "stat" items in the site's own band language (accent-light rule on dark, accent rule on light); estimates only via `data-ct-text="estimate"` inside dashed, italic, unfilled boxes labelled "Your share, an estimate".
- Motion hints: `data-ct-animate="count"` on record numbers only, `draw` on estimate boxes, `reveal` on the `since` and `next` template roots, `data-ct-live` on the hero fact list and the since list; `<span class="ct-new-tag">Just logged</span>` inside record items, hidden by CSS unless `[data-ct-new]`. Page is complete with no motion.
- View transition names: `ct-headline` on `#hero-h` and `#donor-hero-h` (never together), plus `ct-hero`, `ct-ways`, `ct-stats`, `ct-since`, `ct-dollar`, `ct-events`, `ct-news`, `ct-partners`, `ct-next` on the matching `main > *`.
- Re-composition under `html[data-impact-active]` (`main` = flex column, CSS `order`): hero, since, next, where your dollar goes, ways to help, stats, events, news, partners. Strangers keep DOM order.
- `donor-view.sample.json` carries the v2 fields (`live: null`). `?preview=1` (preview.js) only fills v1 slots, so index.html shows just the banner; use `node layer/test/variant-server.mjs` and `/brindlecote/?ct=fx.b.<state>`.
