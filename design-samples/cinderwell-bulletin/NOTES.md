# Sample A: Bulletin Board (Cinderwell Pantry)

- Concept: a community notice board. Flat tan board, flour-paper cards with CSS masking-tape corners, pine hours card pinned first, one marker-yellow. Handwriting comes from Besley italic accents and marker underlines, not a script face.
- Donor block is a yellow "note from the pantry": greeting as the note's own Besley italic heading, records as bold upright lines with a solid rule, estimates as italic muted lines with a pencil-dashed rule. Generated labels ("What the pantry logged", "About your share, an estimate") give the estimate a subject; layer markup is untouched.
- Changes vs original: `.ct-next-link` colors set at host specificity (ink on marker-yellow, AA+); `.ct-record`/`.ct-estimate` weights no longer swapped; slots share the host column width and `figure` margin is zero; hero is a compact two-column note on desktop and the photo is hidden under 480px; `.ct-note` is block; h1/h2 line-height 1.2; all links and buttons are at least 44px tall.
- Also changed: the inline font-size override block is gone, the "about 3 lb" produce cell is styled as an estimate (dashed, italic), the three paths are three different notices (pine, yellow, flour) instead of one list, and the layer's `layer-slots.css` is loaded so the layer-on look is visible. Rotation is at most 0.5deg and is off under 480px.
- Content is unchanged: hours, address, itemized $35 table with "weight is an estimate", volunteer quote, desk form. "Find food" links point to the in-page address card because `visit.html` is not part of this folder. The `layer.js` tag is kept for contract fidelity and simply fails to load offline.
- Verified at 1280, 768 and 390 in the plain state and `?preview=1` with the browser tools: no horizontal overflow, no tap target under 44px, `.ct-next-link` computed as rgb(42,28,22) on rgb(242,193,46), no console-visible layout problems. Motion is a single hours-card settle, disabled under `prefers-reduced-motion`.
- Not done: no keyboard walk-through beyond focus styles being set, and no automated contrast scan of every pair (checked by calculation for the key pairs).
